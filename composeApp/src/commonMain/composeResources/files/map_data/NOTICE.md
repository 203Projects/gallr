# Seoul district boundaries

`seoul_districts.geojson` is the simplified 2013 KOSTAT municipality dataset from
[`southkorea/seoul-maps`](https://github.com/southkorea/seoul-maps), commit
`dbb1dcde2e3c9937684c5a44ab9301888ad63ee6`.

The source dataset is distributed under the Apache License 2.0. The boundary data is used only for
the interactive district-selection overlay; map tiles and labels are supplied separately.
