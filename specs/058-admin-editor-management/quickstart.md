# Quickstart: Admin Editor Management

1. Run the focused admin repository and component tests.
2. Run migration-lineage validation.
3. Clean-replay the local database and run `030_admin_editor_management.test.sql` through the repository database workflow.
4. In fixture mode, open Editors, edit a profile, deactivate access, and restore access.
5. Run the full admin typecheck, test, and build gates.
