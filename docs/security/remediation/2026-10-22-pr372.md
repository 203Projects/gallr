The seven patches are implemented. Database-related fixes are **validation-blocked for release** until the complete database gate is clean. The remaining seven findings below are not fixed.

Database limitation: 73 pgTAP suites were run against a disposable local database. After updating the existing avatar-policy assertion to its stronger canonical-name contract, 72 suites pass. The unchanged `057_legacy_reader_grants_events_editors.test.sql` still fails four table-privilege assertions: anon/authenticated write privileges exist on events/editors in this clean local stack. The existing reader-grant migration grants SELECT without revoking inherited/default writes. These patches do not touch those tables, grants or tests. This is a separate baseline/environment verification issue and is not hidden by weakening the checks.

The full hosted/staging rehearsal, full CLI security-advisor gate, all unrelated concurrency jobs, live Storage HTTP size/MIME enforcement and real provider login were not performed. Do not treat this checkpoint as release authorization. The disposable database was isolated with no network or published ports after the CLI's port-binding check failed.
