# Tasks: Routes (personal and public)

**Input**: Design documents from `/specs/089-personal-routes/`
**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md

**Tests**: Required. Constitution principle II requires test-first for shared logic, and the plan makes every shared, database and web path start from a failing test. Each test task must be run and seen failing before its implementation task starts. Existing suites named as regression contracts (E-D11) must pass unedited.

**Organization**: Setup, then a foundational phase (timeline extraction, route domain, draft repository, migration, route ApiClient, parity file), then one phase per user story in spec priority order. Decision ids (E-D, DR-D, RR, RO) point to `docs/designs/2026-10-07-personal-routes-design.md`.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on an incomplete task)
- **[Story]**: US1 compose and order, US2 save and share, US3 recipient page, US4 manage routes, US5 moderation, US6 measurement, US7 list publicly, US8 staff review, US9 browse popular routes, US10 copy and report, US11 public-route measurement

Common paths:
- `SHARED` = `shared/src/commonMain/kotlin/com/gallr/shared`
- `SHARED_TEST` = `shared/src/commonTest/kotlin/com/gallr/shared`
- `SHARED_HOST_TEST` = `shared/src/androidHostTest/kotlin/com/gallr/shared` (JVM host tests that can read repository files and see `commonTest` fixtures)
- `APP_HOST_TEST` = `composeApp/src/androidHostTest/kotlin/com/gallr/app`
- `APP` = `composeApp/src/commonMain/kotlin/com/gallr/app`
- `APP_TEST` = `composeApp/src/commonTest/kotlin/com/gallr/app`
- `CONTRACTS` = `specs/089-personal-routes/contracts`

Lanes (plan.md): A = shared then composeApp; B = database then web; C = Admin; D = analytics events.
