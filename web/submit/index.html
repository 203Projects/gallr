갤러리 워크스페이스 열기
01

갤러리 확인

기존 갤러리를 찾거나 새 갤러리를 등록하고 소유권 확인을 요청합니다.

02

전시 초안 작성

전시 정보와 표지 이미지를 저장하고 준비가 끝나면 검토를 요청합니다.

03

검토 후 공개

수정 요청과 공개 상태를 확인하고 게시된 전시 페이지로 이동합니다.
